The player performs the in-game checks. This is an opt-in test package, not an
upstream release or support for every GPU/platform.

## Package and source

The current candidate is `MCD2-Graphics-GamePass-main-1f8e166-Windows-x64.zip`.
Its native FG/SR components and shader converters come from the complete
[Windows build of commit 1f8e166](https://github.com/maicol07/mcd2-graphics/actions/runs/38885668945).
The FG guide uses the pinned LLVM MinGW toolchain with a separately compiled Microsoft-ABI ReShade resource bridge. Its lifetime and frame-admission guards are retained.

The UI was rebuilt with NeoRune 0.1.2. CI includes it only after verifying all six source hashes,
its metadata and all three payload hashes against the current commit. The GDK
save bridge is separately compiled from that commit and its source closure is
hash-checked when assembling the package.

Read `SOURCE.txt`, `BUILD-PROVENANCE.json`, `candidate-manifest.json` and the
published qualification summary. The original repaired-preview downloads remain
historical candidates; do not mix their components with this package.

The rebuilt UI keeps HDR controls beside the native Brightness setting when
available, or immediately after its own Upscaler row when that anchor is absent.
Set HDR Output to On as well as enabling native Unreal HDR. A stored Off request
can switch the game back to SDR after startup. If the control requests a restart,
its new value is not yet applied to the running RenoDX bindings. Verify actual
HDR10 output separately from the appearance of the image.


The ZIP contains 17 own-payload files under `payload/`, dependency hashes,
licenses and installation instructions. It includes no vendor runtime DLLs,
diagnostic addons, player saves, private logs or captured game shaders. The
frozen upstream preview tag/assets and manifest remain unchanged.

The GDK package uses the legacy six-slot menu transport explicitly. Consolidated
provider transport and AMD Anti-Lag opt-in remain disabled. Included source-built
AMD/FSR helpers do not qualify AMD or FSR runtime operation on Game Pass; the
trial targets NVIDIA DLSS SR/FG.

## Install and verify

1. Close the game normally and verify `Dungeons-WinGDK-Shipping.exe` has stopped. In the Xbox app, open the game's installation folder. The usual root is `C:\XboxGames\Minecraft Dungeons II\Content`; confirm the executable exists under `Dungeons\Binaries\WinGDK`.
2. Back up the affected files outside the game folder. Preserve your existing `ReShade.ini`, `Dungeons/Config/UserEngine.ini` and `%LOCALAPPDATA%/Dungeons2/Saved/Config/WinGDK/GameUserSettings.ini`. Disable any Vortex deployment that would overwrite the candidate.
3. For an upgrade, move the old MCD2 Graphics payload files listed in its manifest to the backup, preserving their relative paths. Record paths that did not exist. Keep unrelated mods and external dependencies. This prevents old native addons or shaders from silently remaining active.
4. Extract the candidate into a temporary directory. Copy the **contents** of `payload/` into the game's `Content` directory, merging the `Dungeons` tree. Install the external requirements at the paths above. Do not install into `Win64` or change WindowsApps permissions.
5. Preserve other settings and set `r.AllowHDR=1` and `r.AntiAliasingMethod=2` in the existing `[SystemSettings]` section of `Dungeons/Config/UserEngine.ini`. The HDR guide adds the native HDR settings when that mode is wanted.
6. Verify the installed payload and dependency hashes in PowerShell:

```powershell
$package = 'C:\path\to\extracted-candidate'
$game = 'C:\XboxGames\Minecraft Dungeons II\Content'
$manifest = Get-Content -Raw -LiteralPath (Join-Path $package 'candidate-manifest.json') | ConvertFrom-Json
foreach ($entry in $manifest.files) {
    if ((Get-FileHash -LiteralPath (Join-Path $game $entry.path) -Algorithm SHA256).Hash -ne $entry.sha256) {
        throw "Candidate hash mismatch: $($entry.path)"
    }
}
$dependencies = Get-Content -Raw -LiteralPath (Join-Path $package 'dependencies.json') | ConvertFrom-Json
foreach ($entry in $dependencies.files) {
    if ((Get-FileHash -LiteralPath (Join-Path $game $entry.path) -Algorithm SHA256).Hash -ne $entry.sha256) {
        throw "Dependency hash mismatch: $($entry.path)"
    }
}
```

7. Start through the Xbox app. Select borderless window, DLSS Performance, FG On and Reflex On. Restart after a display/presentation-mode change. Enter a mission and keep the game foreground for at least 30 seconds before measuring. FG intentionally suspends when the game loses focus.
8. Compare SR Off with DLSS Performance in the same scene. For FG compare the in-game counter with Xbox Game Bar while FG stays On. The former may show rendered FPS while the latter counts generated presentation frames. Native FG Off retires this experimental session; restart before turning it on again.

## Runtime checks and reports

The complete 1f8e166 package passed a bounded RTX 4080 / NVIDIA 617.42 WinGDK
1.1.2.0 test at 3840x2160, with borderless HDR10, RenoDX native correction,
DLSS Performance, FG On and Reflex On. The player reported about 80 FPS in-game
and 160 in Xbox Game Bar. Logs confirmed 1920x1080 SR input, 155 sampled outcomes
with two presents, HDR10 retained and no coordinator/marker errors. Restart,
mission travel with resumed gameplay and normal game exit passed. The exact CI
guide also passed isolated GPU pixel/resize/callback checks and SDK shutdown.
See `qualification/gdk-gamepass-test-20261016/validation.json` for the bounded
scope and checks. These results do not qualify AMD, other drivers, exclusive
fullscreen, long sessions or HDR colour accuracy.


A successful build or visible toggle does not prove evaluation. Runtime evidence
must show accepted inputs, actual additional presents, correct HDR colour-space
requests when enabled, and SDK/coordinator status zero. Verify a restart, entry
and exit from a mission, and a normal game exit. The published qualification
summary records which of these checks have actually been run on this candidate.

Diagnostics stay under `%LOCALAPPDATA%/Dungeons2/Saved/MCD2Graphics`. Report the
candidate/source commit, game version, GPU/driver, display mode, settings,
counters and symptoms. Inspect/redact any logs before sharing. Do not upload
saves, WGS directories, account identifiers or captured game shaders.

## Restore

Close the game. Move the candidate's listed files to a separate archive and
restore the previous payload to its exact original paths. Remove only new files
whose paths are in the candidate manifest and did not exist before. Restore
backed-up INIs and the previous RenoDX state as appropriate. Do not delete whole
`WinGDK`, `~mods`, save or WGS directories. Removing the GDK addon stops its
six-slot XGameSave bridge; graphics preferences are not automatically restored.

Other GPUs/drivers, exclusive fullscreen, colour accuracy, calibration/menu
transitions and broad long-session behaviour remain unqualified unless the
qualification summary explicitly records otherwise. The released guided
installer's platform support does not change merely because this manual package
is available.
