# Try the Game Pass SR/FG candidate

This is an experimental Windows x64 package for Minecraft Dungeons II Game Pass.
The PR, its code, documentation and packaging were generated by **GPT 6.1 Sol**.
The player performed the in-game checks. This is not an upstream release.

## Downloads

Use the assets on the [Game Pass test prerelease](https://github.com/maicol07/mcd2-graphics/releases/tag/gamepass-test-20261015):

- `MCD2-Graphics-GamePass-test-20261015-Windows-x64.zip`: the tested mod binaries, UI payload, configuration, license, this guide and a SHA-256 manifest.
- `MCD2-Graphics-GamePass-test-20261015-Sources.zip`: repaired preview sources and the exact generated CPU candidate source. The PR commit contains the main-source port. The provenance record distinguishes them.
- `SHA256SUMS.txt`: archive hashes. Check with `Get-FileHash -Algorithm SHA256 <archive>` before extracting.

The binaries are the repaired `v0.3.0-preview.1` candidate tested in game. They
are not a newly qualified build of the complete current `main` package. The
frozen upstream tag, manifest and release assets are unchanged.

## Tested configuration and limits

The bounded test used WinGDK package 1.1.2.0, an RTX 4080, NVIDIA driver 617.42,
3840x2160, borderless window, DLSS Performance, FG On and Reflex On. Runtime
samples reported two presents per host frame with SDK/coordinator status zero.
The player reported smooth motion, about 100 FPS in the game and 180 FPS in
Xbox Game Bar. These counters measure different stages of presentation.

Use borderless mode. Exclusive-fullscreen focus transitions failed during
experimentation. RenoDX was disabled in the successful test; HDR/RenoDX
coexistence is unqualified. This SDR path has no separate HUDless/UI-alpha
images, so UI quality needs more testing. Other game builds, GPUs, drivers,
long sessions and other platforms remain unqualified. Native FG Off retires
this experimental session; restart the game before turning it back on.

## Optional native HDR with RenoDX

The original binary ZIP remains the SDR test package described above. A later
bounded test passed with native Unreal HDR and RenoDX, using the same native
components plus temporary admission logging. See [the HDR configuration guide](GAMEPASS_HDR.md)
and the separate HDR configuration ZIP on the same prerelease. Use that guide
to enable the native HDR path; adding RenoDX with its default SDR upgrade mode
reproduces a black screen. Calibration and wider runtime checks remain limited.

## External requirements

Acquire dependencies separately from their official sources and retain their
license notices. They are not included in the mod archive. The candidate's
`dependencies.json` records the exact tested file hashes and destinations.
All paths below are relative to the game's `Content` directory.

1. Install [Blueprint Loader 2.2](https://www.nexusmods.com/minecraftdungeons2/mods/2?tab=files), following its own instructions. It supplies the UI loader under `Dungeons/Content/Paks/~mods/BlueprintLoader/`. Do not copy another player's files or use a different mod's loader as a substitute.
2. Download the separate [ReShade PR435 dependency](https://github.com/SpinGiantCRM/mcd2-graphics/releases/download/v0.3.0-preview.1/ReShade-PR435-4eb9056-reset-epoch-msvc-x64.zip). Extract its `ReShade64.dll`, rename it `d3d12.asi`, and place it in `Dungeons/Binaries/WinGDK/`. Keep that archive's source/build provenance and license. This is the specific tested framework, not the stock ReShade installer.
3. Download [Streamline 2.14.1](https://github.com/NVIDIA-RTX/Streamline/releases/download/v2.14.1/streamline-sdk-v2.14.1.zip). From production `bin/x64/`, copy `sl.interposer.dll`, `sl.common.dll`, `sl.pcl.dll`, `sl.reflex.dll`, `sl.dlss_g.dll`, `nvngx_dlssg.dll` and `NvLowLatencyVk.dll` into `Dungeons/Binaries/WinGDK/`. Do not use the development/debug DLLs. Keep the NVIDIA notices from the download.
4. Download [DLSS SR 310.9.1 from NVIDIA](https://raw.githubusercontent.com/NVIDIA/DLSS/374959484e79a640feaba44c93ac8cfb0a03f5b5/lib/Windows_x86_64/rel/nvngx_dlss.dll), subject to its NVIDIA license. Place it at `Dungeons/Binaries/WinGDK/MCD2Graphics/ngx-runtime/nvngx_dlss.dll`.
5. Obtain the official [Microsoft GDK October 2025 Update 5, 2510.5.6322](https://github.com/microsoft/GDK/releases/tag/October-2025-Update-5-v2510.5.6322). Install/extract that SDK using Microsoft's installer. Locate its **x64** `xgameruntime.thunks.dll` and copy it to `Dungeons/Binaries/WinGDK/MCD2Graphics/gdk/xgameruntime.thunks.dll`. Verify the hash in `dependencies.json`; do not take an arbitrary thunk DLL from another game. The addon uses the title's runtime and does not replace system Gaming Services.

Do not install a local `_nvngx.dll` or copy driver files. The addon loads the
registered NGX core from the NVIDIA DriverStore. RenoDX is deliberately excluded
from this candidate. Temporarily move any existing `renodx-ue-extended.addon64`
out of the game directory and preserve it in your backup.

## Install manually

1. Exit the game normally and verify `Dungeons-WinGDK-Shipping.exe` has stopped.
2. In the Xbox app, use the game's manage/files action to open its installation. The usual root is `C:\XboxGames\Minecraft Dungeons II\Content`. Confirm the executable exists under `Dungeons\Binaries\WinGDK`. Do not install into `Win64` or change WindowsApps permissions.
3. Outside the game directory, back up every existing file whose path appears in the archive's `candidate-manifest.json`. Record which paths did not exist. Also back up any existing dependency files before replacing them. If Vortex manages these paths, disable its MCD2 Graphics deployment first so it cannot overwrite the candidate.
4. Extract the archive to a temporary directory. Copy the **contents** of its `payload/` directory into the game's `Content` directory, merging the `Dungeons` tree. This installs the five repaired native components, `fg-sdk-bridge.dll`, two INIs, two compiled shaders and the original three-file MCD2 Graphics UI package.
5. Install the external requirements at the paths listed above. Never copy the entire Streamline SDK into the game.
6. Verify every payload hash. In PowerShell, set the paths below, then run:

```powershell
$package = 'C:\path\to\extracted-candidate'
$game = 'C:\XboxGames\Minecraft Dungeons II\Content'
$manifest = Get-Content -Raw -LiteralPath (Join-Path $package 'candidate-manifest.json') | ConvertFrom-Json
foreach ($entry in $manifest.files) {
    $target = Join-Path $game $entry.path
    if ((Get-FileHash -LiteralPath $target -Algorithm SHA256).Hash -ne $entry.sha256) {
        throw "Candidate hash mismatch: $($entry.path)"
    }
}
$dependencies = Get-Content -Raw -LiteralPath (Join-Path $package 'dependencies.json') | ConvertFrom-Json
foreach ($entry in $dependencies.files) {
    $target = Join-Path $game $entry.path
    if ((Get-FileHash -LiteralPath $target -Algorithm SHA256).Hash -ne $entry.sha256) {
        throw "Dependency hash mismatch: $($entry.path)"
    }
}
```

7. In `Dungeons\Config\UserEngine.ini under the game Content directory`, preserve existing settings and set `r.AllowHDR=1` and `r.AntiAliasingMethod=2` in the existing `[SystemSettings]` section. The successful test retained these settings; they do not qualify HDR output. Create the section/file only if absent.
8. Start from the Xbox app. In video settings choose **Windowed Fullscreen / Borderless**, then restart if the display mode changed. Enter a mission, choose **DLSS / Performance**, **Frame generation On**, and **Reflex On**. Keep the game foreground during the check.

## Verify and report

Compare SR Off with DLSS Performance in the same scene first. For FG, compare
the in-game FPS counter with Xbox Game Bar while keeping FG On. The in-game
counter can continue to show rendered FPS while Game Bar counts generated
presentation frames. A menu toggle alone is not proof of evaluation.

Local diagnostics are in `%LOCALAPPDATA%\Dungeons2\Saved\MCD2Graphics`.
Report the game build, GPU/driver, display mode, settings, counters and symptoms.
Inspect and redact any logs before sharing. Do not upload saves, WGS directories,
account identifiers, complete crash reports or captured game shaders.

## Uninstall / restore

Close the game. Restore the files you backed up to their exact original paths.
For paths that did not previously exist, remove only the files listed in the
candidate manifest and the dependency files you added. Restore any moved RenoDX
addon, previous INI contents and mod-manager deployment. Do not delete the whole
`~mods`, `WinGDK`, save or WGS directories. The transport writes only the six
MCD2 Graphics settings/runtime slots through XGameSave; removing it stops that
bridge. It does not restore previous graphics preferences automatically.
