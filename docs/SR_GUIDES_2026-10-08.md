# Independent game SR inputs — 8 October 2026

The current-frame motion/depth/exposure conversion is now shared independently
of NGX. Each consumer retains its own generation, immutable descriptor bundles,
command-recording leases and retirement fences. The existing conversion shader,
DLSS parameter setup and output replacement are unchanged.

This removes the need to start or evaluate DLSS just to supply another SR
provider with guides. It does **not** implement FSR game evaluation yet.

## Live evidence

The exact diagnostic binary in the [receipt](../qualification/providers/sr-guides-2026-10-08.json)
was exercised on Steam build 25754144, CachyOS Proton SLR and RTX 4080 SUPER,
with native Wayland HDR and FG Off.

The receipt records the exact active and cleanup counters. Missing-TAA counts
accumulate while menus are open; they are not used as a gameplay failure count.
An earlier request armed before gameplay timed out and is excluded from the
successful evidence. This is a bounded stationary-hub regression, not a quality
or performance benchmark, Windows runtime qualification, or moving-camera proof.

The sampled unjittered projection matches reversed-Z infinite perspective
(p10=0, p11=1, p14=10, p15=0). The next AMD adapter must still validate its own
depth, motion direction/scale, camera units, timing and exposure contract.

## Private inspection gate

`build.py --native-only --developer-controls` enables an explicit two-frame
inspection request. It is rejected for full release builds; diagnostics are
disabled by default. The request records guides while leaving native/DLSS output
and source scale unchanged. Raw readbacks and constants remain private.

The producer locks the initial normalized extraction body to its exact digest.
Portable fixtures test independent consumers of the same game recording,
failed/successful resets and completed retirement fences. Both CI platforms run
these checks; the native build retains the 16 KiB stack guard.

## Next integration gate

Run the pinned official FSR SDK on these actual game inputs into a separately
owned output. Validate it before replacing the temporal output, then wire Native
AA and provider-specific reduced render sizes with safe Native fallback. FSR FG
and active AMD Anti-Lag qualification remain separate required work.
