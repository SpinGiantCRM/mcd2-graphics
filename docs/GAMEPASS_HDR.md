## What failed and what works in the bounded test

RenoDX's SDR-to-HDR swapchain proxy conflicts with the Streamline/ReShade route.
The isolated GPU test reproduced ten red input pixels and ten black outputs.
RenoDX's native-HDR correction mode preserved all ten outputs, including after
resize, and passed the paired CPU/application callback checks.

The tested configuration enables Unreal's own HDR output and uses RenoDX's
native-HDR correction mode. Both settings are required. `r.AllowHDR=1` alone
does not activate HDR. Unreal also needs its saved `bUseHDRDisplayOutput=True`
preference, otherwise it can switch its swapchain back to SDR after startup.
The HDR checkbox in the mod controls RenoDX tonemapping/calibration; this
manual candidate does not synchronize Unreal's saved HDR preference with it.

With WinGDK 1.1.2.0, RTX 4080, driver 617.42, 3840x2160, borderless, DLSS
Performance, FG On and Reflex On, the follow-up trial retained HDR10/PQ output.
RenoDX was loaded and its SDR upgrade proxy was inactive. Fifty sampled
foreground presents had accepted same-frame guides/images and the correct
queue. SDK outcome samples included 160 with two actual presents and seven
startup samples with one, all with SDK/coordinator status zero. The player
reported smooth motion at about 100 FPS in-game and 180 FPS in Xbox Game Bar.

This in-game capture used a guide addon with extra admission logging and
unchanged guards. That diagnostic addon was removed afterwards; the original
five SR/FG components were restored and hash-checked. The original guide also
passed the isolated RenoDX native-mode GPU tests, including resize. A fresh
in-game capture after removing diagnostics remains unqualified. These are
bounded compatibility checks, not colourimeter measurements or broad platform
qualification.

## Configure with the game closed

1. Enable Windows HDR on the monitor used by the game. Exit the game and verify its process has stopped. Back up the three INIs below and record whether each file existed.
2. Obtain the pinned [RenoDX UE Extended nightly 20260928](https://github.com/marat569/renodx/releases/download/nightly-20260928/renodx-ue-extended.addon64) separately. Its SHA-256 must be `7941e06607c90f187688382fd259d483cde78f54ccb72099b239e8d45f5f87ac`. Retain its MIT license. Place it beside the actual `Dungeons-WinGDK-Shipping.exe` in `Dungeons/Binaries/WinGDK/`.
3. In `Dungeons/Binaries/WinGDK/ReShade.ini`, merge this into the existing global RenoDX section:

```ini
[renodx]
Set_Path=0
```

`Set_Path=0` selects **Upgrade Path Off / Fix native or Engine.ini HDR**.
It keeps RenoDX's shader processing loaded while disabling its conflicting
SDR upgrade swapchain proxy. Preserve profiles, calibration and all other keys.
Do not switch Upgrade Path On for this candidate.

4. In `Dungeons/Config/UserEngine.ini`, under the game `Content` directory, preserve other keys and merge:

```ini
[SystemSettings]
r.AllowHDR=1
r.AntiAliasingMethod=2
r.HDR.EnableHDROutput=1
r.HDR.Display.OutputDevice=3
r.HDR.Display.ColorGamut=2
r.HDR.UI.CompositeMode=1
```

5. In `%LOCALAPPDATA%/Dungeons2/Saved/Config/WinGDK/GameUserSettings.ini`, change the existing HDR flag under the engine settings section. Preserve all other preferences:

```ini
[/Script/Engine.GameUserSettings]
bUseHDRDisplayOutput=True
```

6. Start through the Xbox app. Retain borderless mode, DLSS Performance, FG On and Reflex On. Enable HDR in the mod's video controls for its RenoDX tonemapping/calibration and restart when requested. Changing calibration in the menu does not immediately update the running RenoDX bindings. Native Unreal HDR output is separately controlled by steps 4 and 5.
7. Enter a mission and leave the game foreground for at least 30 seconds. Check motion, UI and colours, then compare the in-game counter with Xbox Game Bar. FG intentionally pauses when the game loses foreground focus; do not disable that guard to make background measurements look active.

`SetColorSpace1(ColorSpace = 12)` in ReShade's log identifies the HDR10/PQ
request. A later request with `ColorSpace = 0` means the game switched to SDR.
Do not infer actual game HDR from Windows HDR, the monitor's HDR mode or a
loaded addon alone. Do not post full logs without inspecting/redacting them.

## Restore

Close the game, restore the three INIs from your own backups and restore the
previous RenoDX addon state. To return to the verified SDR candidate, remove
only the RenoDX addon you added and restore the previous engine/game HDR
preferences. Do not remove other mods or reset whole settings/save directories.

Long sessions, other GPUs/drivers, exclusive fullscreen, colour accuracy and
all calibration/menu transitions remain unqualified. Keep the upstream PR a
draft until the complete current-main package and remaining matrix are tested.
