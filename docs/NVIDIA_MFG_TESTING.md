# NVIDIA MFG Game Pass prerelease installation

Experimental binaries for [PR #57](https://github.com/SpinGiantCRM/mcd2-graphics/pull/57), including the required Game Pass repair from PR #55. The PR, code, UI, documentation and packaging were generated by **GPT 6.1 Sol**; the player performed the in-game checks.

[Download prerelease](https://github.com/maicol07/mcd2-graphics/releases/tag/nvidia-mfg-test-20261017)

## Downloads and scope

Download `MCD2-Graphics-NVIDIA-MFG-312d028-prerelease.1-Windows-x64.zip`, `SHA256SUMS.txt` and this guide. The ZIP contains 17 owned mod files, `candidate-manifest.json`, dependency hashes, build provenance and licenses. Its native source is commit `312d028548712f4c43cae38bda680adc9370ffa6`, built by [this Windows run](https://github.com/maicol07/mcd2-graphics/actions/runs/38932625566); the separately built GDK addon has its own source receipt in the provenance. Release documentation may be newer than the binary-source commit.

This package targets **Xbox Game Pass PC / WinGDK 1.1.2.0 with NVIDIA**. It is a full owned-payload replacement, not an installer for Steam/Win64. First-time users must obtain the external requirements below. Existing users of the working Game Pass test package can retain those exact dependencies. The older prerelease assets remain unchanged.

Verified on RTX 4080 / NVIDIA 617.42 with external MFG Ada Unlock: fixed 2x-6x; live NVIDIA FG On/Off/On; starting with saved Off and enabling in gameplay. The latest candidate also passed one normal exit after SR/3x FG gameplay, with the GDK worker stopped and no remaining game process. Some earlier multiplier/toggle tests used ancestor builds; see `VALIDATION.json` for per-candidate evidence.

Dynamic selection is available when reported by the SDK. Its adaptive behavior is **not yet qualified**, and native RTX 50 hardware is untested. On RTX 40 without an external unlocker, native FG remains 2x. [MFG Ada Unlock](https://github.com/mavismmg/MFGAdaUnlock-RenoDx) is optional, external, unmodified and unbundled; follow its own compatibility instructions. Higher multipliers are shown only when reported by the active runtime. Included AMD helpers do not qualify AMD gameplay.

## Install

1. Close the game normally and confirm `Dungeons-WinGDK-Shipping.exe` has stopped in Task Manager. In the Xbox app, open the game's installation folder. The usual root is `C:\XboxGames\Minecraft Dungeons II\Content`; verify `Dungeons\Binaries\WinGDK\Dungeons-WinGDK-Shipping.exe` exists. Use that Content folder, not WindowsApps or Win64.
2. Download the ZIP and verify its SHA-256 against `SHA256SUMS.txt` with `Get-FileHash -Algorithm SHA256`. Extract it outside the game directory. No compilation or developer SDK setup is needed to install the owned mod binaries; the GDK binding is a separate prerequisite.
3. Back up existing mod files outside the game folder, preserving paths. Save `ReShade.ini`, `Dungeons/Config/UserEngine.ini` and `%LOCALAPPDATA%/Dungeons2/Saved/Config/WinGDK/GameUserSettings.ini`. For an upgrade, use the previous mod manifest to identify its owned files; preserve unrelated mods and external dependencies. Record which candidate paths did not previously exist. Disable Vortex deployment for these files during the trial.
4. Copy the **contents of `payload/`** into the game's **Content** directory. Merge the `Dungeons` tree and replace the candidate's owned files. The final paths include `Dungeons/Binaries/WinGDK/dxgi.dll`, the native addons, and all three `Dungeons/Content/Paks/~mods/MCD2Graphics/MCD2Graphics_P.*` files. Do not copy the ZIP's `payload` folder itself into the game.
5. Install the external requirements at their exact paths above. Preserve other INI settings and ensure `[SystemSettings]` in `Dungeons/Config/UserEngine.ini` contains `r.AllowHDR=1` and `r.AntiAliasingMethod=2`. Do not replace the entire INI.
6. Choose SDR or optional HDR. For SDR, keep the RenoDX UE Extended addon outside the game folder. For HDR with RenoDX, follow the included `GAMEPASS_HDR.md` (or the [repository HDR guide](https://github.com/maicol07/mcd2-graphics/blob/feat/nvidia-multi-frame-generation/docs/GAMEPASS_HDR.md)): native Unreal HDR and RenoDX `Set_Path=0` are both required. The default SDR-upgrade proxy can produce a black screen. Keep your working HDR configuration when upgrading.
7. Verify the installed files using the script below, then launch through the Xbox app. Use borderless window mode. Set the upscaler to NVIDIA DLSS with Performance, Reflex On and Frame Generation On for the initial comparison. Under FG Multiplier, select a supported fixed value such as 2x or 3x. HDR/presentation-mode changes can require restart; the NVIDIA FG On/Off toggle does not. Switching FG providers still requires restart.
8. Enter a mission and stay in the foreground for 30 seconds. FG intentionally suspends in menus, on missing inputs and when the game loses focus. The in-game counter usually reports rendered FPS, while Xbox Game Bar includes generated presentation frames. Compare both in the same scene. Test FG Off then On and normal game exit; report errors or a remaining background process in PR #57.

### Verify the installation

Set the two paths to your extracted package and game Content directory. This script reads files only.

```powershell
$package = 'C:\path\to\extracted-candidate'
$game = 'C:\XboxGames\Minecraft Dungeons II\Content'
$manifest = Get-Content -Raw -LiteralPath (Join-Path $package 'candidate-manifest.json') | ConvertFrom-Json
$dependencies = Get-Content -Raw -LiteralPath (Join-Path $package 'dependencies.json') | ConvertFrom-Json
foreach ($entry in @($manifest.files) + @($dependencies.files)) {
    $target = Join-Path $game $entry.path
    if ((Get-FileHash -LiteralPath $target -Algorithm SHA256 -ErrorAction Stop).Hash -ne $entry.sha256) {
        throw "Hash mismatch: $($entry.path)"
    }
}
Write-Output 'All candidate and required dependency hashes match.'
```

NVIDIA App/driver overrides can select runtime modules outside these paths. File hashes verify the on-disk installation; they do not prove which provider the driver actually loads. Dynamic must be qualified against the active modules, not just the local files.

## Restore

With the game fully closed, restore the backed-up mod payload and INIs to their original paths. Remove only candidate-manifest files that did not exist before this trial. Keep unrelated mods, saves and dependencies. Graphics preferences stored through Xbox Game Save are not reverted by restoring native files; change those in the game's menu. Do not delete WGS folders or alter WindowsApps permissions.

## Reports and remaining limits

Include the game build, GPU/driver, multiplier, HDR/SDR mode and both FPS counters. Mention crashes, artifacts, whether FG resumes after Off, and whether the process disappears after exiting. Private logs can contain local paths or identifiers; inspect/redact them before sharing. Full Dynamic adaptation, native RTX 50, other GPUs/drivers and repeated long-session exits remain unqualified. No vendor runtime DLLs or player data are bundled.
